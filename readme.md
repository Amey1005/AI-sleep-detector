# AI Sleep Detector

A real-time AI-powered sleep and blink detection system using Python, OpenCV, and MediaPipe.

## Features
- Real-time face tracking
- Eye Aspect Ratio (EAR) calculation
- Sleep detection
- Blink counter
- Voice alert system
- FPS monitoring
- Modern UI overlay

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- SciPy

## Installation

bash
pip install opencv-python mediapipe numpy scipy


## Run Project

bash
python main.py


## Controls
- Press Q to exit

## Project Demo
Detects:
- eye closure
- drowsiness
- sleep state
